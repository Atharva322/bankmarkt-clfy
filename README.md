# bankmarkt-clfy
# Introduction
Direct marketing is a primary channel for financial institutions to sell term deposits. The Bank Marketing dataset contains detailed information about clients contacted during marketing campaigns conducted by a Portuguese bank.
This project aims to:
•	Explore the dataset through visualization
•	Build and compare multiple supervised learning models
•	Interpret variable influence
•	Assess model stability using bootstrap resampling
•	Justify handling of correlated predictors
Models used:
•	Logistic Regression
•	Penalized Logistic Regression (LASSO)
•	Ridge Regression
•	Classification Tree
•	Random Forest
The outcome variable (y) indicates whether a client subscribed to a deposit.
This is a binary classification problem.
